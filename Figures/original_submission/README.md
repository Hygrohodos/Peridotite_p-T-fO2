# Original-submission figures (not manuscript v7)

These files keep the figure numbers of the original submission and do not match manuscript v7.
For example, `Fig04_TA98_WZ07_measured_Fe3` is the experiments plot, which is Fig. 5 in v7, and `Fig05`–`Fig08` show the retired Eq. 5 calibration.
They are written by the legacy `scripts/make_figures.py` and `scripts/plot_exp_ta98_wz07.py`.
The v7 figures, Fig1–Fig10, are built by `scripts/paper_figures/make_paper_figures.py` into `$PAPER_FIG_OUT`.
